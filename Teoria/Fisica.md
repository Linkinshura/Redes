# Modelo TCP/IP

## Aplicacion 
Del modelo TCP/IP utiliza las configuraciones de las capas Aplicacion, Presentacion y Sesion del modelo OSI reordenando los Protocolos

Aca se forma el "Dato" dentro estaran las cabeceras correspondientes

## Transporte
Encapsulamiento: Une a traves de "cadenas de caracteres" o "etiquetas" para unir los segmentos

"Datagrama"

## Enlace de Red
Cumple las funciones de de la capa de red y el LLC(Logical Link Control) de enlace de datos 

"TRAMAS"
